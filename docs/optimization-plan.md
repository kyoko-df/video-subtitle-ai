# 声幕 0.3.0 长视频优化设计

目标：命令行可完成转写、翻译、双语导出；长视频翻译可恢复；工作台明确展示模型能力和操作进度。改动沿用现有项目、字幕和导出结构，不修改 SMB 挂载和认证流程。

## 恢复与一致性

检查点位于 CLI 输出目录或 GUI 项目目录的 `.translation-cache/`，保存 UTF-8 字幕译文，因此属于本机项目数据。签名包含源标识、全部原文及时间、目标语言、翻译服务、模型标识、思考设置和提示词版本；任一变化产生不同检查点。超时、并发、批大小和输出上限不影响签名，允许调整后继续。

检查点只包含通过编号、数量和非空文本校验的结果。编号乱序可重排；重复、缺失和多余编号拒绝。单个协调线程写检查点，原子替换文件，工作线程仅发送结果事件。损坏或不匹配的检查点明确报错；取消恢复选项或 `--no-resume` 后重新生成对应检查点。

不检查同一模型标识背后的权重变化；更换权重、量化版本、模型模板或服务侧参数后，希望整片结果一致时应重新开始。本机制保证同一翻译调用内部的并发写入一致性，不支持多个 CLI 进程同时处理同一检查点。

一条命令流程另保存 ASR JSON 缓存，签名包含源绝对路径、大小、修改时间、音轨和全部识别配置。翻译失败后重复相同命令可跳过 ASR；改变源文件或识别配置会重新转写。默认不覆盖已有正式输出，重做已有输出需 `--overwrite`。

## 失败策略

认证、模型配置、内存不足、连接拒绝和超时停止并给出操作建议。超时可能意味着模型仍在推理；不会立即反复提交相同推理。429 / 500 / 502 / 503 / 504 和连接中断采用有限退避，最多用户指定的重试次数。上下文、输出截断、JSON / 编号错误按字幕列表递归拆半；不会拆开单条字幕或伪造译文。

任务仍保持原字幕和已下载文件。用户选择继续时只提交未完成字幕。取消为协作式：当前 HTTP 请求需返回或超时；停止提交后续批次，已写入的检查点可复用。

## LM Studio 能力适配

模型清单使用 [原生模型接口](https://lmstudio.ai/docs/developer/rest/list)。仅在接口返回 404、405 或 501 时回退；认证失败、响应损坏不伪装成旧版本。兼容接口没有模型类型时显示能力未知。

默认思考模式通过 `/v1/chat/completions` 的 [严格结构化输出](https://lmstudio.ai/docs/developer/openai-compat/structured-output) 翻译。显式思考模式采用 [原生 `/api/v1/chat`](https://lmstudio.ai/docs/developer/rest/chat) 的 `reasoning`，并设置 `store=false`；该接口未声明 JSON Schema 字段，使用提示词要求 JSON，再执行同一严格编号校验和拆批策略。原生返回的思考内容不作为译文。

服务报告并发容量小于客户端请求数时提前拒绝；未报告时允许用户设置并由服务排队。容量不需要精确相等，客户端请求数不能超过已报告容量。并发 2 不保证提速；模型格式、服务版本、内存和实际连续批处理支持决定结果。

## 状态契约

- 转写：轮询 `GET /api/jobs/{id}` 的 `status`；`done` 后可获取字幕。
- 翻译 / 烧录 / 封装：轮询 `operation.status`；原来的转写 `status=done` 保持不变。
- 后台操作 `queued` / `running` 是处理中；`done` / `error` / `cancelled` 是终态。
- 翻译 `operation.stats` 包含完成字幕数、总字幕数、已恢复数、完成批次、总批次、处理中批次、重试、拆批和经过秒数。批次数按原始调度批次计，拆出的子批次另计 `splits`，百分比按已校验字幕数计算。
- 中断后 `operation.status=error`、`interrupted=true`，保留设置和已保存的进度。再次提交同一翻译设置，默认恢复检查点。

## 验证及环境责任

自动回归覆盖 CLI 完整流程、部分成功后的恢复、输入变化、损坏检查点、取消、有限重试、递归拆批、乱序并发、原生思考适配、模型回退、重复保留和删除撤销、环境检测及旧项目恢复。视频导出使用真实 FFmpeg。浏览器流程使用独立工作区和模拟 LM Studio。

LM Studio 安装、模型下载 / 加载、服务侧并发和上下文配置、硬件升级、Hugging Face 网络及 FFmpeg 安装由运行环境负责。程序提供配置、诊断和可恢复行为。用户报告的 2.1 倍加速、特定模型质量和两小时视频耗时属于该次实测，本次修改不据此承诺普遍性能。实际验证范围见 [VALIDATION.md](../VALIDATION.md)。
